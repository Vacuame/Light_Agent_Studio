# Skill: update-agent-system

用于修改 Agent 架构本身。

## 主要角色

- Administrator

## 适用场景

- 修改规则
- 修改角色
- 修改技能
- 修改质量门
- 修改项目配置

## 流程

1. 明确要修改什么。
2. 说明为什么要修改。
3. 分析影响范围。
4. 检查是否需要同步修改其他文件。
5. 通过管理门。
6. 用户确认。
7. 修改文件。
8. 记录变更。

## 输出

- 更新后的规则、角色或技能文件
- 必要时写入 `docs/decisions/`
- 更新 `state/active.md`

## 禁止

- 不允许无影响分析直接改规则。
- 不允许绕过用户确认。
