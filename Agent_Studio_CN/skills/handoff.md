# Skill: handoff

用于阶段交接和会话结束前整理。

## 目标

- 防止断片
- 告诉下一个角色从哪里继续
- 区分临时状态和正式产物

## 必读文件

- `state/active.md`
- 当前任务相关产物

## 流程

1. 总结当前任务。
2. 列出已完成内容。
3. 列出未完成内容。
4. 列出权威文件。
5. 列出临时假设。
6. 列出下一步。
7. 更新 `state/active.md`。
8. 更新 `state/handoff.md`。
9. 必要时追加到 `state/session-log.md`。

## 输出

- `state/active.md`
- `state/handoff.md`
- `state/session-log.md`
