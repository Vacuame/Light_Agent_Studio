# 自动护栏

自动护栏是提醒和机械检查，不代替用户判断。

当前版本先写规则，不实现脚本。

## 会话开始提醒

开始新会话时，应提醒读取：

```text
state/active.md
state/handoff.md
rules/project-config.md
```

## 压缩前保存

压缩或长任务中断前，应提醒更新：

```text
state/active.md
state/handoff.md
```

## 危险操作提醒

以下操作前必须确认：

- 删除文件
- 大规模移动目录
- 修改项目配置
- 修改规则、角色、技能
- 引入新依赖
- 重写架构

## 步骤进展提醒

每个阶段完成前，需要用户确认。

用户确认后，才可以：

- 更新 `state/handoff.md`
- 更新正式产物
- 标记当前阶段完成

## Git 提交

当前不做提交前自动检查。

用户手动提交更安全。
