# 开发门

适用于代码交给测试前。

## 谁需要读

- Developer
- 使用 `skills/implement.md` 时的执行者

## 检查清单

- 代码是否按模块设计实现？
- 代码是否遵守模块设计中的实现落点？
- 是否偏离设计？
- 如果偏离设计或实现落点，是否记录原因并等待确认？
- 是否更新实现说明？
- 是否有明显风险？
- 是否需要更新架构或模块设计？
- 是否提供给 Tester 的测试入口？
- 是否提供给 Tester 的注意事项？
- 是否有未完成项或 TODO？

## 输出要求

交接前必须给出：

```text
实现内容：
修改文件：
实现落点遵循情况：
偏离设计：
风险：
未完成项：
给 Tester 的测试入口：
建议结论：PASS / CONCERNS / BLOCKED
```
