# 管理门

适用于修改规则、角色、技能、质量门、项目配置前。

## 谁需要读

- Administrator
- 使用 `skills/update-agent-system.md` 时的执行者

## 检查清单

- 为什么要改？
- 改哪些文件？
- 会影响哪些角色？
- 会影响哪些技能？
- 是否需要同步更新质量门？
- 是否需要同步更新 README 或总规则？
- 是否需要迁移旧文档？
- 是否可能造成旧流程失效？

## 输出要求

修改前必须给出：

```text
修改原因：
影响范围：
涉及文件：
风险：
是否需要同步更新：
建议结论：PASS / CONCERNS / BLOCKED
```
