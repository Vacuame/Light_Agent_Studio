# 管理门

适用于检查 Agent Studio 系统变更产物。

结论格式见 `rules/quality-gates.md`。角色权限见当前 `agents/<role>.md`。

## 适用交付物

- 规则文件变更
- 角色提示词变更
- 技能 SOP 变更
- 质量门变更
- 项目配置变更
- 状态结构或协作协议变更
- Agent Studio 总览或 README 的系统说明变更

## 使用时机

当规则、角色、技能、质量门、项目配置或状态结构准备修改前使用。

## 检查清单

- 为什么要改？
- 改哪些文件？
- 会影响哪些角色？
- 会影响哪些技能？
- 是否需要同步更新质量门？
- 是否需要同步更新 README、总规则或 overview？
- 是否需要处理现有文档？
- 是否可能造成现有流程不再适用？
- 如果修改状态结构，是否说明现有状态文件如何处理？
- 如果删除任务目录或状态文件，是否获得用户确认？
- 如果调整 handoff/report 协议，是否说明交接、回报、关闭、完成记录、删除规则？
- 是否保持了单一权威来源，避免把同一规则复制到多个层级？

## 输出要求

修改前必须给出：

```text
修改原因：
影响范围：
涉及文件：
影响角色：
影响技能：
现有流程处理：
风险：
是否需要同步更新：
建议结论：PASS / CONCERNS / BLOCKED
```
