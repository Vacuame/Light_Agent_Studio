# 管理门

适用于修改规则、角色、技能、质量门、项目配置、状态结构前。

## 谁需要读

- Administrator
- 使用 `skills/update-agent-system.md` 时的执行者

## 检查清单

- 为什么要改？
- 改哪些文件？
- 会影响哪些角色？
- 会影响哪些技能？
- 是否需要同步更新质量门？
- 是否需要同步更新 README、总规则或 overview？
- 是否需要迁移旧文档？
- 是否可能造成旧流程失效？
- 如果修改状态结构，是否说明旧状态文件如何处理？
- 如果删除任务目录或状态文件，是否获得用户确认？
- 如果引入任务级 handoff/report，是否说明交接、回报、关闭、归档、删除规则？

## 输出要求

修改前必须给出：

```text
修改原因：
影响范围：
涉及文件：
影响角色：
影响技能：
旧流程兼容或迁移：
风险：
是否需要同步更新：
建议结论：PASS / CONCERNS / BLOCKED
```
