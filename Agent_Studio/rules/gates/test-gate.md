# 测试门

适用于测试结果支持任务回报或关闭前。

## 谁需要读

- Tester
- 使用 `skills/test.md` 时的执行者

## 检查清单

- 测试是否执行？
- 测试范围是否覆盖验收标准？
- 测试是否通过？
- bug 是否记录？
- 未解决问题是否写清楚？
- 风险是否写清楚？
- 是否可以关闭当前测试对象？
- 如果不能关闭，下一步应该交给谁？
- 如果写 `report.md`，测试结论、通过项、失败项、风险和对上层任务的影响是否清楚？
- 如果任务有子任务，必要子任务是否已有回报？

## 输出要求

回报或关闭任务前必须给出：

```text
测试对象：
测试范围：
测试结果：
通过项：
失败项：
bug 列表：
遗留风险：
是否可以关闭：
任务目录：
report：
建议结论：PASS / CONCERNS / BLOCKED
```
