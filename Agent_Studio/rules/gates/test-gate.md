# 测试门

适用于检查测试类交付物。

结论格式见 `rules/quality-gates.md`。角色权限见当前 `agents/<role>.md`。

## 适用交付物

- 测试计划
- 测试结果
- bug 记录
- 测试阶段回报
- 关闭建议

## 使用时机

当测试结果准备支持任务回报、风险判断或关闭建议前使用。

## 检查清单

- 测试是否执行？
- 测试范围是否覆盖验收标准？
- 测试是否通过？
- bug 是否记录？
- 未解决问题是否写清楚？
- 风险是否写清楚？
- 是否可以建议关闭当前测试对象？
- 如果不能建议关闭，下一步应该交给谁？
- 如果写 `report.md`，测试结论、通过项、失败项、风险和对上层任务的影响是否清楚？
- 如果任务有子任务，必要子任务是否已有回报？

## 判定档位

- `PASS`：测试已执行，验收标准全部覆盖，无失败项，遗留风险已写清。
- `CONCERNS`：有失败项但已全部记录，或部分验收项只能手动验证且已说明原因。
- `BLOCKED`：测试未执行、验收标准有未覆盖项、或失败项未记录/被包装成通过。

## 输出要求

回报或关闭建议前必须给出：

```text
测试对象：
测试范围：
测试结果：
通过项：
失败项：
bug 列表：
遗留风险：
是否可以建议关闭：
任务目录：
report：
建议结论：PASS / CONCERNS / BLOCKED
```
