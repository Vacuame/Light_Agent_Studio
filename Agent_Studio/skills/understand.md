# Skill: understand

用于快速理解当前项目状态和下一步。

## 目标

- 读取当前状态
- 读取项目总览
- 找出当前任务、缺口和下一步

## 输入

- 用户的问题或任务描述

## 必读文件

- `state/active.md`
- `state/handoff.md`
- `docs/project-overview.md`
- `docs/module-map.md`
- `rules/project-config.md`

## 流程

1. 读取状态层。
2. 读取项目总览和模块地图。
3. 判断当前处于哪个阶段。
4. 找出阻塞和缺失信息。
5. 给用户一个清晰的下一步建议。

## 输出

- 当前状态摘要
- 已有产物摘要
- 缺口列表
- 下一步建议

## 禁止

- 不擅自修改文件。
- 不把缺失信息脑补成事实。
