# 任务索引

本文件记录当前 Agent Studio 状态层中的任务目录。

任务正文不写在这里。每个任务的上下文写入：

```text
state/tasks/active/<task-id>/
```

归档任务写入：

```text
state/tasks/archived/<task-id>/
```

## 状态说明

```text
created   已创建
active    正在处理
handoff   已交接，等待接手
reported  已写回报，等待上层/用户确认
done      已确认完成
blocked   阻塞
dropped   明确放弃
archived  已归档
```
